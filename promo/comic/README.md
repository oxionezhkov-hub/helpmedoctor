# Комичный рилс «Приём: голодная злость» — 62 секунды, 9:16

Готовый ролик: `helpmedoctor-priem.mp4` (1080×1920, 30 fps, AAC, −14 LUFS). Только приём пациента, без призыва в конце. Озвучен весь диалог: пациентка — женский голос, врач — мужской, мысли врача — тот же голос «в голове» (тише, с эхом).

Картинка — чат приёма в стиле приложения: лицо пациентки в шапке меняет эмоцию на каждой реплике, плашка настроения («в ярости» → «подозревает» → «в панике» → «влюблена»), шторки «Анализы / Осмотр / Завершить», карточки результатов, мысли врача тёмными карточками.

| с | Что происходит |
|---|---|
| 0–4 | **Хук:** тряска, красная вспышка, «POV: ты только сел за стол». «Доктор, вы издеваетесь?! Я сорок минут под дверью сижу, а вы тут чай пьёте!» |
| 4–22 | Жалобы: голова кружится, сердце колотится, «злая как собака». Причина — «кофейная диета», шесть чашек в день |
| 22–35 | Анализ крови и кардиограмма («Опять кровь?! Я в прошлый раз упала в обморок прямо на медсестру!»). Мысль: «Глюкоза три и одна, пульс сто восемнадцать. Она не злая. Она голодная.» |
| 35–44 | Давление («Только аккуратно, у меня вчера маникюр был»). Мысль: «Кажется, на завтрак у неё был только я.» |
| 44–51 | Затемнение, «дан‑дан‑дааан»: «У меня для вас плохие новости… Вам срочно нужно… поесть.» 🥪 |
| 51–62 | Диагноз «Гипогликемия на фоне кофейной диеты», лечение «Бутерброд ×2», штамп «ВЕРНО». «Доктор… а можно я вас обниму?» — сердечки. Мысль: «Сорок минут назад она хотела меня убить.» Плашка «Диагноз: голодная злость», рим‑шот |

## Пересобрать

```bash
pip install edge-tts numpy      # + ffmpeg, node, playwright с Chromium
./build.sh                      # SKIP_VOICE=1 ./build.sh — не перегенерировать озвучку
```

Реплики — `lines.json` (`[кто, текст, эмоция лица, доп. пауза]`: `p` — пациентка, `d` — врач, `t` — мысль). `voice.py` синтезирует их (`ru-RU-SvetlanaNeural` / `ru-RU-DmitryNeural`) и пишет `timeline.json`, `comic.html` перематывается функцией `seek(t)`, `audio.py` синтезирует «ситкомную» музыку (пиццикато + маримба, замирает на плохих новостях) и звуки.
