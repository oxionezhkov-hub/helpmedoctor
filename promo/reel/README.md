# Рилс «Help me, Doctor» — 29 секунд, 9:16

Готовый ролик: `helpmedoctor-reel.mp4` (1080×1920, 30 fps, AAC, −14 LUFS).

Как сделан — без внешних видеосервисов:

- **Озвучка** — Microsoft Neural TTS (`ru-RU-DmitryNeural`) через `edge-tts`, по фразам из `lines.json`. Сервис отдаёт тайминги слов — по ним синхронизированы все анимации и караоке-субтитры (`timeline.json`).
- **Картинка** — `reel.html`: HTML/CSS-моушн в цветах и шрифтах бренда (Literata + Manrope). Каждая анимация привязана к слову озвучки (`data-at="exams:УЗИ"`), страница перематывается функцией `seek(t)`, а `render.mjs` (Playwright) снимает кадр за кадром и отдаёт в ffmpeg.
- **Музыка и звуки** — `audio.py` синтезирует на numpy: пэд Am–F–C–G, бас, арпеджио, бит со «сбивкой» на появлении логотипа, сердцебиение в хуке, писк ЭКГ, вжухи на переходах, щелчки сообщений, удар штампа. Музыка приглушается под голос (sidechain).

## Сценарий

| с | Кадр | Голос |
|---|---|---|
| 0–3.6 | «Знать болезнь и узнать её у пациента — разные навыки», учебник ≠ пациент | Знать болезнь и узнать её у пациента — это разные навыки. |
| 3.6–6.4 | ЭКГ-линия → логотип, «Help me, Doctor», специальности | Это тренажёр врача с виртуальными пациентами. |
| 6.4–11.4 | Чат с пациентом Мироном Л., голосовое сообщение | Пациент говорит только то, о чём вы спросили. Текстом или голосом. |
| 11.4–16.2 | Плитки обследований, результат ФГДС, скрытый диагноз | Назначаете анализы, УЗИ, гастроскопию — результаты как у настоящего пациента. |
| 16.2–22.2 | Диагноз со штампом «ВЕРНО», разбор 4,5/5 по КР Минздрава | Ставите диагноз — и сразу получаете разбор по клиническим рекомендациям Минздрава: что упустили и чем лечить. |
| 22.2–24.4 | «2 пациента в день — бесплатно» | Два пациента в день — бесплатно. |
| 24.4–29.2 | Логотип, комментарий с кодовым словом «ПРИЁМ» печатается и отправляется | Напишите в комментариях слово «приём» — и мы пришлём ссылку. |

**Кодовое слово для комментариев — «ПРИЁМ».** На него нужно отвечать ссылкой (вручную или автоответом). Название сервиса голос не произносит: синтез читает «Help me, Doctor» неестественно, поэтому оно только на экране.

## Пересобрать

```bash
pip install edge-tts numpy      # + ffmpeg, node, playwright с Chromium
./build.sh                      # SKIP_VOICE=1 ./build.sh — не перегенерировать озвучку
```

Поменять текст — правьте `lines.json` (и при необходимости `data-at` в `reel.html`, они ссылаются на слова). Посмотреть анимацию в браузере без рендера: `npx serve .` и открыть `reel.html?play`.
