## Пересобрать

```bash
pip install edge-tts numpy      # + ffmpeg, node, playwright с Chromium
./build.sh                      # музыка и звуки без голоса; WITH_VOICE=1 — с синтетическим голосом
```

Устроено так же, как `promo/reel/`: `nina.html` перематывается функцией `seek(t)`, анимации привязаны к словам озвучки (`data-at="app:бац"`), `render.mjs` рендерит кадры, `audio.py` синтезирует музыку (хаус 128 BPM) и звуки. Тайминги слов берутся из синтезированной озвучки (`voice.py`); в последней фразе пауза перед «Пиши…» укорочена вручную в `timeline.json`. Шрифты берутся из `../reel/fonts`.
