# Рилс «Нина × Help me, Doctor» — 15 секунд, 9:16

Готовый ролик: `nina-reel.mp4` (1080×1920, 30 fps, ~15,8 с, −14 LUFS).

Весёлый POV-ролик от лица Нины (автор канала @i_am_doctorrr): фото Нины из `content/telegram-channel/img/nina/`, стикеры, эмодзи, конфетти, камера дёргается в бит, комикс-вспышка «БАЦ!».

| с | Кадр | Голос |
|---|---|---|
| 0–2 | В тёмных очках в аудитории: «POV: Я НИНА», «4 курс · лечфак» | Привет, я Нина, четвёртый курс! |
| 2–4 | Обнимает скелет: «лучший друг», сердечки, «теория ✓» | Скелет я уже обняла — теорию знаю. |
| 4–6,4 | Скрип пластинки, ч/б, кинорамка, наезд камеры, грустный тромбон 🥲 | А вот вести пациента — удаётся редко. |
| 6,4–11,2 | Дроп: тренажёр — чат с пациентом, анализы, диагноз «ВЕРНО», «БАЦ!», разбор | Поэтому тренируюсь в Help me, Doctor… и бац, разбор! |
| 11,2–12,3 | С зачёткой: «4,5/5», конфетти, «зачёт ✓» | Четыре с половиной! |
| 12,3–15,8 | С ягодами, подмигивает: «2 пациента в день — БЕСПЛАТНО», «Залетай →» | Два пациента в день бесплатно. Залетай! |

Правила канала соблюдены: ни одного выдуманного события из жизни Нины. В кадре только то, что видно на фото, и то, что указано в описании канала (4 курс, тренирует приём в боте). Фото с чужими лицами (`stetoskop-para`, `operacionnaya-maski`) не использованы, человек на фоне `koridor-zachetka` обрезан.

**Голос синтетический** (Microsoft Neural, `ru-RU-SvetlanaNeural`), это не голос Нины. Лучше, если Нина начитает текст из `lines.json` сама. Как подставить её запись: положить файлы фраз в `seg/0.wav … seg/5.wav` и поправить тайминги, либо подстроить текст и запустить `voice.py` с её записью вместо TTS.

## Пересобрать

```bash
pip install edge-tts numpy      # + ffmpeg, node, playwright с Chromium
./build.sh                      # SKIP_VOICE=1 ./build.sh — без перегенерации голоса
```

Устроено так же, как `promo/reel/`: `nina.html` перематывается функцией `seek(t)`, анимации привязаны к словам озвучки (`data-at="app:бац"`), `render.mjs` рендерит кадры, `audio.py` синтезирует музыку (хаус 128 BPM) и звуки. Шрифты берутся из `../reel/fonts`.
