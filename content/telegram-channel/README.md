# Telegram-канал «Нина станет врачом» (@i_am_doctorrr)

Автор — Нина, 4 курс лечфака, Санкт-Петербург. Посты публикует бот через GitHub Actions (`.github/workflows/tg-channel.yml`).

## Как выложить посты
1. Создать `queue/<дата>-<тема>.json` — шаги по порядку (формат — в шапке `scripts/tg-channel.mjs`).
2. Проверить: `node scripts/tg-channel.mjs queue/<файл>.json --dry`.
3. Закоммитить файл отдельным коммитом в новую ветку `tg/<дата>-<тема>` и запушить — workflow опубликует только этот файл.

## Что публикуем
- Примерно каждый 4-й пост — с картинками (карусель из `decks.mjs` → `node scripts/tg-cards.mjs`).
- Остальные — текстовые клинические кейсы с ответом под спойлером (`<tg-spoiler>`), PDF-шпаргалки (`pdf/*.html` → `node scripts/build-pdf.mjs`), короткие советы.
- Реклама тренажёра — только в закрепе (одна кнопка на бота) и изредка мягко в тексте.
- Медицинские факты — по клиническим рекомендациям и учебникам; никаких выдуманных историй от лица Нины без её согласия.
