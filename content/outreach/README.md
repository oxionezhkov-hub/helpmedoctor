# Точечная рассылка: организаторы, СМИ, сообщества

Материалы, чтобы рассказать о тренажёре организаторам конференций и олимпиад, форумов, редакциям журналов и порталов, админам сообществ, СНО и студсоветам медвузов, а также проектам с той же аудиторией.

| Файл | Что это |
|---|---|
| `contacts.xlsx` | база контактов: название, сегмент, категория, онлайн/офлайн, описание в одно предложение, ссылка, отдельные колонки с email, телефонами и соцсетями, приоритет, источник, статус. Лист «Сводка» — сколько контактов в каждом сегменте |
| `contacts.csv` | та же база для импорта в Google Таблицы, Notion или CRM |
| `help-me-doctor-presentation.pdf` | презентация на 8 слайдов для вложения в письмо, ссылки кликабельные, есть QR на тренажёр |
| `templates.md` | письма по сегментам, сообщения для Telegram и VK, готовый пост для партнёра, скрипт звонка, напоминание |
| `data/*.json` | исходные данные базы по сегментам — правьте здесь, а не в xlsx, если будете пересобирать |

## Как работать с базой

1. Откройте `contacts.xlsx` (или загрузите `contacts.csv` в Google Таблицы, чтобы вести её вместе), отфильтруйте по «Приоритет» = A и начните с них.
2. Выберите шаблон в `templates.md` по сегменту, подставьте имя и одну конкретную деталь про адресата.
3. Своя метка для каждого партнёра: `https://helpmedoctor.ru/app?from=p_<имя>`. Регистрации по метке видны в админке → «Источники».
4. Отмечайте «Статус» и «Кто ведёт», чтобы один контакт не получил два письма.

Контакты собраны из открытых официальных страниц (колонка «Где нашли контакты»). Сайты мероприятий и составы оргкомитетов меняются, поэтому перед отправкой проверьте, что адрес актуален. Пишем каждому лично, а не массовой рассылкой. Так письма не попадут в спам. К тому же личное деловое предложение конкретному адресату рекламой не считается, а массовая рекламная рассылка без согласия получателей нарушает ст. 18 закона «О рекламе».

## Пересборка

```bash
python3 content/outreach/build-contacts.py   # data/*.json → contacts.xlsx + contacts.csv (нужен openpyxl)
node content/outreach/build.mjs              # presentation.html → help-me-doctor-presentation.pdf (нужен playwright)
```

Скриншоты в `img/` сняты с демо-приёма на главной странице сайта. QR в `img/qr-app.svg` ведёт на `https://helpmedoctor.ru/app?from=partner_deck`.

## Автоматическая рассылка по почте

Скрипт `scripts/outreach-mail.mjs` и расписание `.github/workflows/outreach-mail.yml`: по будням в 09:20 МСК отправляют 10 писем с ящика из секрета `SMTP_USER`, с паузой 2,5–5,5 минуты между письмами.

- **Письма.** `mailing/letters.json` — тема и первый абзац у каждого адресата свои, общая часть в `mailing/templates.mjs`. Письма идут простым текстом, без вложений, на один адрес — одно письмо. Подпись и лимиты задаются в `mailing/config.json`.
- **Напоминания и ответы.** Через 6 рабочих дней скрипт отправляет одно напоминание в той же переписке. Ответы и отказы доставки он находит в ящике по IMAP, и таким адресатам больше не пишет.
- **Где смотреть, кому ушло.** Ветка `outreach-state`, файл `status.csv`. Сводка приходит в Telegram, если задана переменная `OUTREACH_TG_CHAT`.
- **Включение.** `"enabled": true` в `mailing/config.json`. Пока там `false`, по расписанию ничего не отправляется.
- **Тест.** Actions → «Рассылка партнёрам» → Run workflow → в поле `test_to` укажите свой адрес. Придут 3 первых письма с пометкой [ТЕСТ], базу и состояние тест не трогает.
- **Прочитать все письма заранее.** `node scripts/outreach-mail.mjs --preview letters.md`.
- **Секреты.** `SMTP_USER` — адрес Gmail, `SMTP_PASS` — пароль приложения. Для Яндекса поменяйте `smtp` и `imap` в config на `smtp.yandex.ru` и `imap.yandex.ru`.
