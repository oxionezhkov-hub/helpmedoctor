Картинки — `content/vk-group/img/` (пересобрать: `node scripts/vk-cards.mjs cover avatar`).

- **Название:** Для будущих врачей
- **Адрес:** vk.com/dlya_budushchih_vrachey (если занят — vk.com/budushchie_vrachi)
- **Тип:** группа (если создаёте заново — «Сообщество по интересам» → тематика «Образование»)
- **Описание:**

> Для студентов-медиков, ординаторов и всех, кто станет врачом.
>
> Каждый день:
> 🩺 клинические случаи с разбором по клиническим рекомендациям Минздрава;
> 💡 лайфхаки для учёбы, практики и аккредитации;
> 📚 полезные материалы: где брать КР, атласы, задачи, калькуляторы.
>
> Без воды и без «подписывайтесь». Спорим и разбираем в комментариях.
>
> Потренировать приём пациента: https://helpmedoctor.ru/app?from=vk_group

- **Статус (под названием):** Клинический случай каждый день — ответ в разборе 👇
- **Сайт:** https://helpmedoctor.ru/?from=vk_group
- **Возрастное ограничение:** 16+ (медицинские темы)

## 2. Картинки
- **Аватар:** `avatar.jpg` (1000×1000). ВК обрежет в круг — знак уже по центру. Миниатюру выбрать по всему кругу.
- **Обложка:** `cover.jpg` (1920×768): Управление → Обложка → Загрузить. На телефоне ВК показывает середину, всё важное уже в центре.

## 3. Разделы (Управление → Разделы)
- Включить: **Стена — открытая** (или ограниченная, если начнётся спам), **Фотографии**, **Обсуждения**, **Ссылки**, **Статьи**.
- Выключить: Товары, Аудио, Видео (пока нет роликов), Мероприятия.
- **Главный блок:** Обсуждения. **Второстепенный:** Ссылки.

## 4. Обсуждения (создать 3 темы)
1. **«Предложи тему для разбора»** — «Какой случай, симптом или раздел разобрать? Пиши — лучшие темы выйдут отдельным постом».
2. **«Вопросы по аккредитации и ОСКЭ»** — «Спрашивай про станции, чек-листы и подготовку — отвечаем и собираем частые вопросы в посты».
3. **«Полезное от подписчиков»** — «Делись ресурсами, которые реально помогли: атласы, приложения, каналы. Ссылка + одна фраза, зачем это».
