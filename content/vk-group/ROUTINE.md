# Рутина группы ВК «Для будущих врачей»: 5 постов в день

Группа для студентов-медиков: полезные материалы, лайфхаки учёбы и практики, клинические случаи с разбором.

Расписание (Москва): **09:00, 12:00, 15:00, 18:00, 21:00** — каждый запуск публикует ровно один пост. Слот — час запуска по Москве: 08–10 → `09`, 11–13 → `12`, 14–16 → `15`, 17–19 → `18`, 20–23 → `21`. Ветка поста — `vk/<дата>-<слот>`.
Посты уходят через ленту RSS: `content/vk-group/queue/<дата>-<тема>.json` → workflow «Группа ВК» → https://helpmedoctor.ru/vk/rss.xml → ВК сам забирает новые записи (обычно в течение часа).

## Жёсткие правила
- **Реклама — ровно 1 пост из 5** (в среднем один в день, слот любой). Перед постом посмотри 4 предыдущих (ветки `vk/*`): если среди них нет поста со ссылкой на helpmedoctor — этот пост с призывом, иначе — **ни слова о тренажёре и ни одной ссылки на helpmedoctor**.
- Пост с призывом — всё равно польза (случай, лайфхак), а в конце одна-две строки: «Потренировать такой приём на ИИ-пациенте: https://helpmedoctor.ru/app?from=vk_group». В json — `"link": "https://helpmedoctor.ru/app?from=vk_group"`. У остальных постов `link` нет.
- **Только обычный текст.** ВК не понимает HTML и markdown: без `<b>`, `**`, `==`. Выделение — эмодзи-маркеры и короткие абзацы. Скрипт такие посты не пропустит.
- Медицинские факты — только по клиническим рекомендациям Минздрава (cr.minzdrav.gov.ru) и учебникам. Никаких выдуманных цифр, исследований, цитат и людей. Дозы — только если они из КР.
- Клинический случай — **ответ и разбор открытым текстом** в том же посте после строки «Разбор 👇». Опросов в ленте нет.
- Голос — сообщество, а не персонаж: «мы» про группу, к читателю на «ты», как старший курс младшему. Живо и коротко, без канцелярита (проверка `scripts/site/style.mjs`), без «в этом посте мы рассмотрим», без «подписывайтесь».
- Тема не повторяет последние 30 постов группы (ветки `vk/*`), рубрика не повторяет предыдущий пост. За день — все три рубрики.

## Рубрики (по кругу: следующая после рубрики предыдущего поста)
1. **Клинический случай.** Жалоба словами пациента → 2–3 детали осмотра и анализов → «Что думаешь?» → «Разбор 👇»: диагноз, на чём легко ошибиться, что по КР. Темы — то, что спрашивают на 4–6 курсе и на аккредитации.
2. **Лайфхак студента.** Одна конкретная вещь, которая экономит время или спасает на практике/экзамене: как учить фарму, как вести дневник практики, как не завалить станцию ОСКЭ, как читать ЭКГ по шагам, приложения и шаблоны. Одна идея — один пост.
3. **Полезные материалы.** Подборка 3–5 проверенных ресурсов с объяснением, зачем каждый: рубрикатор КР, атласы, бесплатные курсы, калькуляторы шкал, банки задач. Только реально существующие ресурсы с рабочими ссылками.

## Оформление поста
- `title` — первая строка поста, до 80 символов: вопрос, парадокс или узнаваемая ситуация («Почему ОАК начинают читать не с гемоглобина»), без эмодзи в начале.
- `text` — 600–1500 символов: абзацы по 1–3 предложения, пустая строка между ними; списки — «•» или эмодзи, до 5–7 пунктов. В конце — вопрос в комментарии или вывод.
- `image` — **всегда** картинка: карточка из `content/vk-group/cards.mjs` (`node scripts/vk-cards.mjs <ключ>`, `CHROME_PATH=/opt/pw-browsers/chromium-1194/chrome-linux/chrome`), 3–5 пунктов, без ника Telegram-канала.
- Хештеги — одна строка в конце: `#длябудущихврачей` + рубрика (`#клинслучай`, `#лайфхак_медика`, `#материалы_медика`).

Пример:
```json
{
  "title": "Где брать клинические рекомендации и как найти нужную за минуту",
  "text": "Абзац…\n\nАбзац…\n\n#длябудущихврачей #материалы_медика",
  "image": "content/vk-group/img/rubrikator-kr.jpg"
}
```

## Порядок запуска
1. `git fetch origin main '+refs/heads/vk/*:refs/remotes/origin/vk/*'`. Дата — `TZ=Europe/Moscow date +%F`, слот — по часу (см. «Расписание»). Если ветка `vk/<дата>-<слот>` уже есть — пост этого слота вышел, заверши работу.
2. Прошлые посты: `git for-each-ref --sort=-committerdate refs/remotes/origin/vk/ --count=30`, для каждой — `content/vk-group/queue/*.json` из последнего коммита. Выпиши рубрики, темы и были ли ссылки на helpmedoctor (правило 1 из 5).
3. `git checkout -B vk/<дата>-<слот> origin/main`. Карточку — в `cards.mjs`, собери, **закоммить первым коммитом** («Группа ВК: материалы <тема>»).
4. Файл `content/vk-group/queue/<дата>-<тема-латиницей>.json`. Проверка: `node scripts/vk-feed.mjs <файл> --dry` — без ошибок. Перечитай вслух: крючок в первой строке, звучит как живая речь, факты сверены, нет выдуманных людей.
5. **Отдельным последним коммитом** — только этот json («Группа ВК: <заголовок>»). `git push -u origin vk/<дата>-<слот>`.
6. Проверь workflow «Группа ВК» (`vk-group.yml`, ветка `vk/<дата>-<слот>`) — успех. Упал — исправь новым файлом `…-v2.json` отдельным коммитом.
7. Итог в чат: рубрика, заголовок, с призывом или без, результат workflow. В main не пушить, PR не открывать.
