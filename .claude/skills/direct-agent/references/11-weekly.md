# 11. Еженедельная оптимизация

Раз в неделю, данные за 7–14 дней.

## Цена заявки по срезам

Отчёт `CUSTOM_REPORT` с конверсиями по цели, срезы:

- группы и объявления;
- пол и возраст (`Gender`, `Age`);
- устройства (`Device`);
- регионы (`LocationOfPresenceName`);
- время суток — по отчёту Метрики, если нужно.

## Повышения и понижения ставок

Для каждого среза с достаточными данными (от 10 заявок или от 3 × целевой CPA расхода):

```
корректировка = целевой CPA / фактический CPA − 1
```

Ограничь от −50% до +50% за один раз. Пример: CPA сегмента вдвое выше цели → −50%. Сегменты без данных не трогай.

Корректировки задаются на уровне кампании или группы (сервис BidModifiers). В ЕПК часть корректировок ограничена — проверь, какие доступны для типа кампании.

## Объявления

- Сравни объявления в группе при минимум 1 000 показов у каждого.
- Слабое по CTR и по конверсии — замени новым вариантом из 2–3 углов (цена, скорость, доверие).
- Для комбинаторных — посмотри, какие заголовки и тексты Директ показывает чаще всего, слабые элементы замени.

## Группы

- Цена заявки в группе выше средней в 1,5 раза и больше — предложи понизить ставку на 20–30% или разобрать фразы.
- Группа без показов — проверь фразы, ставку, модерацию.

## Отчёт

Сформируй недельный отчёт (`14-reports-insights.md`) и список правок на согласование.
