# 16. Ошибки и грабли

## Ошибки API

| Код | Что значит | Что делать |
|---|---|---|
| 53 | ошибка авторизации | токен неверный или отозван — получить новый |
| 58 | незавершённая регистрация | подать или дождаться одобрения заявки: Директ → Инструменты → API → «Мои заявки» |
| 152 | недостаточно баллов | подождать следующего часа, собирать правки пачками |
| 513 | логин не подключён к Директу | проверить аккаунт или Client-Login |

Отчёты Reports отвечают кодами 201 и 202, пока строятся, — это не ошибка. Повтори запрос через столько секунд, сколько в заголовке `retryIn`.

## Грабли и решения

| Ошибка | Решение |
|---|---|
| Частотность без Вордстата — модель выдумывает | подключить Вордстат, цифры только оттуда |
| Агент путает цифры (1 400 ₽ вместо 950) | сверять 2–3 числа повторным запросом |
| Агентский кабинет: данные соседнего клиента | в каждой задаче — клиент и кампания |
| «Применять рекомендации» включено по умолчанию: до +4% бюджета за неделю | выключить флажок в блоке «Директ помогает» |
| Первый запуск на автомате с сетями: 3 106 ₽ и 0 заявок | первую неделю только поиск |
| Автотаргетинг цепляется за слова в тексте | убрать слова не по теме, смотреть запросы с первого дня |
| Объявления загрузились, но не ушли на модерацию | отправить на модерацию и проверить статус |
| «Лучший», «№1» — отклоняет модерация | запретить эти слова в промпте |
| Цель считает не заявки (198 против 42) | проверка цели до запуска (`02-goal-check.md`) |
| Частые правки стратегии — обучение с нуля | стратегию не чаще раза в 1–2 недели |
