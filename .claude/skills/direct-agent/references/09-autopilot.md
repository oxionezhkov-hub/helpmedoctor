# 9. Автопилот

## Ритм

| Когда | Что делает агент | Нужно ли «да» |
|---|---|---|
| Каждый час (8:00–23:00) | расход за сегодня против плана, скачок цены клика >30%, кампании без показов, отклонённые объявления, баланс | нет; при перерасходе — пауза и сообщение |
| Каждое утро | минус-слова из вчерашних запросов, площадки без заявок, сверка заявок с CRM | да — список правок в Telegram |
| Раз в неделю | цена заявки по срезам, ставки, новые тексты, отчёт | да — на правки |
| Раз в 2–4 недели | стратегия, цели, структура | решает человек |

План для проверок — `direct/plan.json` (`templates/plan.example.json`).

## Где запускать — спроси человека

### 1. Рутина Claude Code — проще всего

Задача по расписанию в облаке Claude Code: сервер не нужен.
- Создай рутину с репозиторием, где лежит папка `direct/`, и подключённым MCP Директа.
- Промпт рутины — короткий и конкретный, например: «Открой direct/plan.json. Сравни расход за сегодня по каждой кампании с дневным планом. Перерасход больше 20% — поставь кампанию на паузу, запиши в direct/journal.md и пришли сообщение. Иначе ничего не делай».
- Отдельные рутины на час, утро и неделю.

### 2. Воркер Cloudflare — свой код и кнопки в Telegram

- `wrangler.toml`:
  ```toml
  [triggers]
  crons = ["0 5-20 * * *", "0 6 * * *", "0 7 * * 1"]  # время UTC
  ```
- Секреты: `wrangler secret put DIRECT_TOKEN`, `ANTHROPIC_API_KEY`, `TG_BOT_TOKEN`, `TG_CHAT_ID`.
- В обработчике `scheduled` по `event.cron` выбирай задачу: собрать данные из Reports API → отдать Claude API с правилами из `10-daily.md` / `11-weekly.md` → получить JSON правок → отправить в Telegram.
- Правки храни в KV под id, кнопки — `inline_keyboard` с `callback_data: "apply:<id>"` / `"reject:<id>"`. Вебхук бота на том же воркере применяет правки через API Директа и пишет журнал.

### 3. Функция Яндекс Облака — если всё должно быть в России

- Cloud Functions + таймер-триггер. Cron Яндекс Облака из 6 полей: `0 * ? * * *` — каждый час (время UTC).
- Код тот же, что для воркера. Секреты — в Lockbox, состояние — в Object Storage или YDB.

### 4. Локально

- Claude Code или Codex на своём компьютере. Для расписания — cron или launchd с запуском без интерфейса:
  ```
  claude -p "<промпт задачи>" --allowedTools "<только нужные инструменты>"
  codex exec "<промпт задачи>"
  ```
- Работает, пока компьютер включён. Хорошо для старта и тестов.

## Сообщение в Telegram

Коротко и с действиями:

```
Директ · 24 окт, утро
Вчера: расход 4 120 ₽ (план 4 000), заявок 6, цена 687 ₽
Предлагаю:
• 9 минус-слов (мусор на 612 ₽): бесплатно, своими руками, …
• отключить 2 площадки: 0 заявок на 1 340 ₽
[Применить] [Отклонить] [Показать подробно]
```

## Правило ограничений

У каждой задачи — только нужные права. Часовой задаче хватит чтения статистики и паузы кампании. Запись минус-слов и ставок — только задаче, которая применяет согласованные правки.
