# 4. Семантика и минус-слова

## Порядок

1. **Стартовые фразы.** Из брифа, сайта и старого кабинета — 10–30 «маркерных» фраз: товар + действие («ремонт iphone», «замена экрана iphone»).
2. **Спрос.** По каждой — Вордстат: частотность, похожие запросы, сезонность за 12 месяцев. Только реальные цифры из Вордстата.
3. **Расширение.** Из выдачи Вордстата бери целевые хвосты: город, срочность, модель, цена («ремонт iphone 13 на дому москва»).
4. **Чистка.** Убери нецелевые: «своими руками», «бесплатно», «курсы», «вакансии», «скачать», «форум», бренды конкурентов (если не договорились иначе).
5. **Группы по намерению.** Одна группа — одна задача клиента: «замена экрана», «замена батареи», «срочный ремонт на дому». Не по словам, а по смыслу: в одной группе фразы, на которые подходит одно и то же объявление и одна посадочная.
6. **Посадочные.** Каждой группе — самая точная страница сайта.

## Операторы соответствия

- `!слово` — фиксирует форму слова.
- `+на` — учитывает предлог или союз.
- `"фраза"` — только запросы из этих слов, без добавок.
- `[слово слово]` — фиксирует порядок.

На старте не переусердствуй: широкие фразы плюс сильные минус-слова дают больше данных для обучения.

## Минус-слова

- **На уровне кампании** — общий мусор: бесплатно, своими руками, вакансии, курсы, скачать, отзывы сотрудников.
- **На уровне группы** — чтобы группы не пересекались (кросс-минусовка): в группе «ремонт iphone» минус «экран», если для экрана своя группа.
- **Из отчёта по запросам** — ежедневно, см. `10-daily.md`.

Перед добавлением минус-слова проверь, не отрежет ли оно целевые запросы: прогони его по списку целевых фраз. Ошибочный минус молча убивает трафик.

## Автотаргетинг

Автотаргетинг подбирает запросы по тексту объявления. Слова не по теме в тексте уводят показы. Включай только целевые категории запросов, смотри отчёт по запросам с первого дня.

## Результат

Запиши группы, фразы и минус-слова в файл кампании `direct/campaigns/<имя>.json` (`templates/campaign.example.json`).
