# 8. Запуск и первые 72 часа

## Чек-лист перед запуском

- [ ] Цель Метрики проверена (`02-goal-check.md`).
- [ ] Кампания только на поиск, сети выключены. Сети — отдельной кампанией через неделю.
- [ ] Расписание показов — только часы, когда принимают заявки.
- [ ] Регионы — только те, где работаете.
- [ ] Недельный бюджет и стратегия выставлены (`12-strategy.md`).
- [ ] В настройках кампании, блок «Директ помогает», выключен флажок «Автоматически применять рекомендации». Он включён по умолчанию и может сам поднять недельный бюджет до 4% за 7 дней. Это делается в интерфейсе — попроси человека.
- [ ] Объявления отправлены на модерацию.
- [ ] Записан `direct/plan.json`: дневной план расхода, целевой CPA, цель.

## Первые 72 часа

- **Каждые 2–3 часа:** прошли ли объявления модерацию, есть ли показы, нет ли перерасхода.
- **Через 24 часа:** первый отчёт по запросам — минус-слова (`10-daily.md`). Это самый важный момент: мусор виден сразу.
- **Через 72 часа:** CTR по группам, цена клика, первые заявки. Слабые объявления пока не трогать — мало данных.

## Чего не делать в первую неделю

- Не менять стратегию и цели — сбивает обучение.
- Не включать сети «на пробу» в той же кампании.
- Не делать выводов о цене заявки по 1–3 конверсиям.
