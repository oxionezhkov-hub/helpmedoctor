# 10. Ежедневная оптимизация

Каждое утро, за вчера (или за 3 дня, если данных мало).

## Минусация

1. Отчёт по поисковым запросам: `SEARCH_QUERY_PERFORMANCE_REPORT`, поля `Query, CampaignName, AdGroupName, Clicks, Cost, Conversions`, в `Goals` — id цели из брифа.
2. Отметь кандидатов:
   - запрос не про продукт клиента (Figma вместо MCP-сервера, «бесплатно», «своими руками»);
   - расход на запрос больше 1,5 × целевой CPA и 0 заявок — подозрительный, проверь смысл.
3. Для каждого кандидата выбери минус-слово, а не всю фразу: короче и шире, но проверь, что оно не режет целевые фразы.
4. Реши уровень: общий мусор — на кампанию, пересечение групп — на группу.
5. Собери список правок с объяснением: «бесплатно — 14 кликов, 0 заявок, 612 ₽».

## Площадки (если работают сети)

- Отчёт `CUSTOM_REPORT` с полем `Placement`.
- Кандидат на отключение: кликов больше 50 или расход больше 2 × целевой CPA, а заявок 0.
- Перед отключением спроси про звонки: часть заявок может приходить по телефону и не попадать в цель.
- Отключение — в настройках кампании, список запрещённых площадок.

## Сверка с CRM

Заявки из CRM за вчера против конверсий Директа. Расхождение больше 30% два дня подряд — сообщи: возможно, сломалась цель или форма.

## Результат

Файл правок `direct/changes/<дата>.json` (`templates/changes.example.json`) и сообщение в Telegram или в диалоге. Применять — только после «да» (`15-safety.md`).
