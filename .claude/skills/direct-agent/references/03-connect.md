# 3. Подключение

## Самый простой путь — готовый MCP-сервер

Если в сессии ещё нет инструментов Директа, предложи подключить MCP-сервер. Человеку ничего не нужно набирать: ты сам ставишь сервер и присылаешь ссылку на вход в Яндекс ID.

| Вариант | Как подключить | Доступ |
|---|---|---|
| askads, удалённый | `claude mcp add --transport http yandex-direct https://mcp.askads.ru/mcp` | только чтение — для аудита |
| askads, локальный | `claude mcp add --transport stdio --scope user yandex-direct -- npx -y mcp-yandex-direct@latest`; для Codex: `codex mcp add yandex-direct -- npx -y mcp-yandex-direct@latest` | чтение и запись |
| axisrow, плагин | `/plugin marketplace add etopro/plugin-marketplace` → `/plugin install yandex-direct@plugin-marketplace` | чтение и запись, профили доступа |

После установки: «подключи Директ» → ссылка на вход → человек присылает код. Песочница для тестов: переменная `YANDEX_DIRECT_SANDBOX=true` (askads).

Все эти серверы сторонние. Перед установкой скажи об этом человеку, а для записи в живой кабинет начинай с режима чтения.

## Свой доступ по API

Нужен для автопилота на своём сервере (воркер, функция) или если MCP не подходит.

1. **Приложение.** oauth.yandex.ru → создать приложение → платформа «Веб-сервисы» → Redirect URI `https://oauth.yandex.ru/verification_code` → доступы: «Использование API Яндекс.Директа», для Метрики — «Получение статистики, чтение параметров своих и доверенных счётчиков». Сохрани ClientID.
2. **Заявка в Директе.** Директ → Инструменты → API → «Мои заявки» → указать ClientID. Пока заявку не одобрили, API отвечает ошибкой 58 «Незавершённая регистрация».
3. **Токен.** Открыть `https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>`, войти аккаунтом с доступом к кабинету, забрать токен.
4. **Хранение.** Токен — только в секретах: переменная окружения, `wrangler secret put`, секреты Яндекс Облака. Никогда не проси прислать токен в чат и не записывай в файлы проекта.

## Агентский кабинет

Каждый запрос — с заголовком `Client-Login: <логин клиента>`. Чтобы тратить баллы агентства, а не клиента, — `Use-Operator-Units: true`.

## Вордстат

Подключи доступ к Вордстату (через MCP-сервер, где он есть, например Yurich-ru/yandex-ads-mcp, или по API Вордстата). Без него частотность не используй вообще.

## Проверочный запрос

Сделай один запрос на чтение и покажи результат человеку:

```
POST https://api.direct.yandex.com/json/v5/campaigns
Authorization: Bearer <токен>
{"method":"get","params":{"SelectionCriteria":{},"FieldNames":["Id","Name","State"]}}
```

«Подключено, вижу 12 кампаний: …». Ошибка — смотри `16-troubleshooting.md`.

## Баллы

У API дневной лимит «баллов». Заголовок ответа `Units: 10/20828/64000` — потрачено / осталось / суточный лимит. Лимит пополняется каждый час на 1/24. Ошибочный запрос стоит 20 баллов. Поэтому: правки — пачками, справочники — кешировать, новое — проверять в песочнице `api-sandbox.direct.yandex.com`.
