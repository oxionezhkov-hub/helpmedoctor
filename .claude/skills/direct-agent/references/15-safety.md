# 15. Безопасность и согласования

## Что можно без согласования

- Читать Директ, Метрику, Вордстат, CRM.
- Готовить отчёты, списки правок, файлы кампаний.
- Показывать, что изменится.
- **Ставить кампанию на паузу при перерасходе** больше 20% от дневного плана на текущий час (порог — в `direct/plan.json`). Сразу сообщи.

## Что только после «да»

- Ставки, корректировки ставок, бюджеты.
- Минус-слова и запрещённые площадки.
- Стратегии, цели, целевой CPA.
- Создание, запуск и удаление кампаний, групп, объявлений.
- Загрузка баз в Яндекс Аудитории.

## Как получать «да»

1. Собери правки в файл `direct/changes/<дата>.json` (`templates/changes.example.json`): каждая правка — что, где, почему, ожидаемый эффект.
2. Покажи человеку списком или отправь в Telegram с кнопками.
3. «Да» относится только к этому списку. Если после согласия список поменялся — согласуй заново.
4. Примени ровно согласованное, без «заодно поправил».

## Журнал

Каждое применённое изменение — строка в `direct/journal.md`:

```
2026-10-24 09:12 | Ремонт iPhone · Поиск | +9 минус-слов | мусор на 612 ₽ за вчера | согласовал: владелец, Telegram
```

Автоматического отката у API нет. Журнал нужен, чтобы вручную вернуть, если что-то пошло не так.

## Доступы

- Начинай с режима «только чтение». Запись — когда человек увидел пару отчётов и доверяет.
- Токены — только в секретах, никогда в чате, файлах проекта и логах.
- Каждой автоматической задаче — минимум прав (`09-autopilot.md`).
- В агентском кабинете — всегда явный клиент.
